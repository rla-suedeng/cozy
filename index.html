    새 목록 추가

    영상 끝에서 이 시간만큼 남으면 바로 다음 화로 넘어감. 화마다 다르면 크레딧 시작 시점에 위의 분홍 버튼을 누르면 그 화만 따로 기억함. 이미 저장된 재생목록을 다시 넣으면 보던 위치는 그대로 유지됨.

    전체 회차 불러오기 (200개 넘는 목록)

    유튜브 플레이어는 재생목록을 200개 정도까지만 넘겨줌. 유튜브 Data API 키를 넣으면 재생목록 전체를 제목까지 한 번에 받아옴. 키는 이 기기에만 저장됨.

    1. 유튜브 로그인

    로그인 화면에서 프리미엄 계정으로 로그인한 뒤, 위쪽의 「완료」나 ✕를 눌러 앱으로 돌아와 2번을 누르세요. 영상이 시작될 때 광고가 안 나오면 성공임.
